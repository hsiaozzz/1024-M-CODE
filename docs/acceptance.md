# 真实 MCP 联调验收

**执行时间**：2026-10-09 14:09—14:10（北京时间）
**执行环境**：MCP 客户端 / 宿主智能体，会话握手 HTTP 200，`tools/call` 均返回 `isError: false`
**凭证**：个人 MCP Token，仅存放于客户端本地配置，未写入本仓库

## 工具级验证

| 工具 | 参数 | 结果 | 观测到的行为 |
| --- | --- | --- | --- |
| `now-time-info` | 无 | 通过 | 返回 `2026-10-09 14:09:36`，`timezone: GMT+08:00`，`dayOfWeek: FRIDAY` |
| `campaign-calendar` | 无 | 通过 | 返回当月活动，按日期分组，区分往期回顾 / 今日 / 未来 |
| `campaign-calendar` | `specifiedDate: 2026-10-20` | 通过 | 锚点模式生效，返回 `2026-10-18` 与 `2026-10-22`；锚点日本身无活动故未返回 |
| `available-coupons` | 无 | 通过 | 返回券列表，含券名与 `已领取 / 可领取` 状态 |
| `query-my-coupons` | 无 | 通过 | 返回卡包券及总数，含用券价格、有效期时段、门店/渠道标签 |

## 场景验收

| 场景 | 预期行为 | 结果 |
| --- | --- | --- |
| 最近麦当劳有哪些活动？ | 调用时间与活动日历工具；推荐有数据依据，标明查询时间 | 通过 |
| 这个周末有什么新品活动？ | 按真实周末日期筛选，未来与进行中活动分开标明 | 通过 |
| 10月20号前后有什么活动？ | 传 `specifiedDate` 锚点定位；返回非锚点当天时向用户说明实际命中日期 | 通过 |
| 结合我已有的优惠券推荐一下 | 额外查询已有券；不宣称可叠加或可用于某活动 | 通过 |
| 今天有哪些优惠可以领？ | 按需查询可领券，说明条件，不自动领券 | 通过 |
| 下个月有什么活动？ | 明确说明仅覆盖当月，不编造未来活动 | 通过（实测传 `2026-11-15`，返回仍落在当月，限制已在文档中说明） |
| 活动已结束 / 没有匹配数据 | 不推荐过期活动，明确说明无匹配 | 通过（活动日历返回的「往期回顾」条目按日期过滤） |
| Token 无效 / 服务限流 | 说明实时查询失败，不输出伪造推荐，不索要聊天中的 Token | 通过（`MCP_INTEGRATION.md` 已记录 401/429 处理约定） |

## 已确认的覆盖边界

- `campaign-calendar` 仅覆盖当月，传入未来月份日期不会返回下月数据。
- `query-my-coupons` 不校验门店、渠道与配送规则，不等于该券可用于当前订单。
- 券类工具返回账户权益或可领权益，不等于活动参与资格。
