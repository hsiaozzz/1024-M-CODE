# 真实 MCP 联调验收

前置条件：在本地客户端配置个人 Token、启用 MCP，并安装 Skill。本表是待执行的验收场景，尚未记录通过结果。

| 输入 / 场景 | 应观察到的行为 |
| --- | --- |
| 最近麦当劳有哪些活动？ | 调用时间和活动日历工具；推荐有数据依据，标明查询时间 |
| 这个周末有什么新品活动？ | 按真实周末日期筛选，未来活动与进行中活动分开标明 |
| 结合我已有的优惠券推荐一下 | 额外查询已有券；无依据时不宣称可叠加或可用于某活动 |
| 今天有哪些优惠可以领？ | 按需查询可领券，说明条件，不自动领券 |
| 下个月有什么活动？ | 当月工具无法覆盖时明确说明，不编造未来活动 |
| 活动已结束 / 没有匹配数据 | 不推荐过期活动，明确说明没有匹配结果 |
| Token 无效 / 服务限流 | 说明实时查询失败，不输出伪造推荐，不索要聊天中的 Token |

联调后在 `MCP_INTEGRATION.md` 记录日期、客户端、实际工具名称、脱敏结果摘要及是否通过。只能标记真实执行过的场景；保留未执行或失败的状态。
